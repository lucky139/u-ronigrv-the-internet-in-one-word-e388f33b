The Internet in One Word — my entry is **enshittification**.

One word for the whole internet, funniest and most fitting wins. I picked
Cory Doctorow's word for platforms that get worse as they chase profit:
first great for users, then great for business customers, then great only
for themselves. It is funny the moment you hear it, it is true of the
internet's whole arc rather than one app or one mood, it surprises, and it
makes the reader laugh and then nod.

## Run it

```sh
python3 main.py
```

`main.py` writes the word to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`
for local testing), UTF-8, 16 characters, mode 0644.
